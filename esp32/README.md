# CuGo RC（ESP32 版）

ESP32 から Cytron MD20A ×2 を PWM + DIR で駆動し、スマホや PC のブラウザから Wi-Fi で CuGo V3 を操縦します（カメラなし）。
Raspberry Pi 版と操作方法・安全機能は同じです。
USB シリアルでつないだ Jetson から自律走行させることもできます（[Jetson との接続](#jetson-との接続自律走行)）。

## 配線

ESP32 DevKit（ESP32-WROOM / D0WD）の場合です。

| 信号 | ESP32 GPIO |
|---|---|
| 左 MD20A PWM | GPIO25 |
| 左 MD20A DIR | GPIO26 |
| 右 MD20A PWM | GPIO32 |
| 右 MD20A DIR | GPIO33 |
| GND | GND |

- **ESP32 と MD20A ×2 の GND を必ず共通化**してください（2 台とも）。
- 信号は 3.3V です。MD20A は 3.3V 入力に対応しています。
- **推奨: 各 PWM 線に 10kΩ のプルダウン抵抗（PWM–GND 間）。** 書き込み中やリセット中はピンが浮くため、モーターが勝手に回るのを防ぎます。
- ピンは `include/config.h` で変更できます。GPIO0 / 2 / 5 / 12 / 15（起動時の動作に関わるピン）と、GPIO34〜39（入力専用）は使わないでください。

## 書き込み

PlatformIO（VS Code 拡張または CLI）を使います。ESP32 を USB でつないで、このフォルダで次を実行します。

```bash
cd esp32
pio run -t upload        # ビルドして書き込み
pio device monitor       # シリアルログを見る（115200bps、Ctrl+C で終了）
```

`pio` コマンドが見つからない場合は `~/.platformio/penv/bin/pio` を使ってください。

## 操縦

1. スマホ / PC の Wi-Fi で **`CuGo-RC`** に接続します（パスワード **`cugo-rc-1234`**）
2. ブラウザで **`http://192.168.4.1/`** を開きます

| 操作 | PC | スマホ |
|---|---|---|
| 前進 / 後退 | W / S | ジョイスティック上下 |
| 旋回 | A / D | ジョイスティック左右 |
| 低速モード（×0.4） | Shift を押しながら | — |
| 停止 | Space | 赤い停止ボタン |

- 操縦できるのは最初に接続した 1 台のみです（他は「閲覧のみ」）。
- 画面のバーは実際の duty です（入力 × 出力上限。上 = 前進、下 = 後退）。

### 出力上限（duty の最大値）の調整

画面の **「出力上限」スライダー**（5〜100%）で、duty の最大値を変えられます。

- 指を離した時点で ESP32 に送られ、**本体に保存**されます（電源を切っても残ります）。
- 走行中に変えても、すぐに反映されます。
- 変更できるのは操縦者のみです。他の端末にも新しい値が表示されます。
- ESP32 の青色 LED は操縦者が接続中のとき点灯します。

### 家の Wi-Fi に参加させる場合

`include/config.h` の `WIFI_STA_SSID` / `WIFI_STA_PASS` を設定して書き込み直します。
起動時にシリアルログに表示される IP アドレス（または `http://cugo.local/`）を開きます。
15 秒以内に接続できなければ、自動でアクセスポイントモード（`CuGo-RC`）になります。

## Jetson との接続（自律走行）

ESP32 の USB（CP2102）を Jetson につなぐと、Jetson の `cugo_base_node`（`jetson/src/cugo_base`）が USB シリアルで走行指令を送ります。
ESP32 は足回りの管理役として、ウォッチドッグ・加速度制限・速度上限・Web 手動操縦との切り替えを受け持ちます。

### モード

優先順位は **動作テスト > Web 手動 > Jetson 自律** です。

| モード | 画面 / `$T` | 内容 |
|---|---|---|
| 待機 | I | 有効な指令源がない（出力 0） |
| 自律 | A | Jetson の指令で走行中。duty は **±`AUTO_MAX_DUTY`（50%）** に制限（Web の出力上限スライダーは掛けません） |
| 手動 | M | Web の操縦者が操縦中（出力上限スライダーを掛けます。従来通り） |
| テスト | X | 動作テスト中 |

- **Web の操縦者がいないとき**は自律走行が許可されています（Jetson 単独で走れます）。
- **操縦者が接続すると手動**になり、Jetson の指令では走りません。画面の **「自律走行を許可」** にチェックを入れると自律に切り替わります（操縦者のみ操作できます）。
- 自律中に操縦者がジョイスティック / WASD で操作すると（入力 > 0.05）、**すぐに手動に戻ります**。
- **停止ボタン / Space** で停止し、自律走行の許可も外れます。
- 操縦者が切断すると停止し、自律走行の許可に戻ります。
- 画面のヘッダーに現在のモード（待機 / 自律 / 手動 / テスト）が表示されます。青色 LED は操縦者接続中または自律中に点灯します。

### シリアルプロトコル（v1）

115200bps、8N1、改行区切りの ASCII 行です。形式は `$<BODY>*<HH>`（`HH` は BODY の全バイトの XOR を大文字 16 進 2 桁で表したもの）。
`$` で始まらない行は人間向けのログです。

| 向き | 行 | 内容 |
|---|---|---|
| Jetson → ESP32 | `$D,<l>,<r>*HH` | 左右の duty（-1.0〜1.0、前進が正、invert 前の論理値）。20〜50Hz で送り続ける（ハートビートを兼ねる） |
| Jetson → ESP32 | `$S*HH` | 即時停止（自律中のみ。加速度制限を無視して 0） |
| ESP32 → Jetson | `$T,<mode>,<l>,<r>,<cap>,<flags>,<bad>*HH` | 20Hz のステータス |

例: `$D,0.250,-0.250*69`、`$S*53`、`$T,A,0.250,-0.250,0.50,5,0*26`

- `$T` の `l` / `r` は現在の出力 duty（加速度制限後、invert 前）、`cap` は `AUTO_MAX_DUTY`。
- `flags` はビットフラグ（10 進）: 1 = 自律許可中、2 = Web 操縦者接続中、4 = Jetson の指令を受信中。
- `bad` は起動以降の不正行（チェックサム不一致・形式不正・長すぎる行）の数です。
- `$D` の値は ±1 にクランプされます。`nan` / `inf` / 指数表記などは不正行として無視します。
- Jetson の指令が **300ms 途絶えると即座に停止**します（Jetson・ROS・USB のどれが止まっても止まります）。

シリアルモニタの `t` / `s` / `?` はそのまま使えます（改行なしの 1 文字。`$` 行の途中の文字はコマンドになりません）。
ただし Jetson が USB をつかんでいる間は、PC からシリアルモニタを開けません。

## 動作テスト（一人で確認する）

**ESP32 の BOOT ボタンを押すと、5 秒後に**左右のモーターを順番に動かします（PC もスマホも不要）。

| 順 | 動作 |
|---|---|
| 1 / 2 | 左 前進 / 後退 |
| 3 / 4 | 右 前進 / 後退 |
| 5 / 6 | 両方 前進 / 後退 |
| 7 / 8 | その場で左旋回 / 右旋回 |

- 各動作 2 秒・間に 1 秒停止・速度 30%（× 出力上限）。初回は **タイヤを浮かせて** 行ってください。
- 待ち時間中は青色 LED が速く点滅、テスト中はゆっくり点滅します。
- **もう一度 BOOT ボタンを押すと中止**します（ブラウザの停止ボタンでも中止）。
- シリアルモニタからは `t` で開始、`s` で中止、`?` で状態表示ができます。
- 速度や時間は `include/config.h` の `SELFTEST_*` で変更できます。

## 自動停止の条件

| 条件 | 内容 |
|---|---|
| 指令途絶 | 最後の指令から 300ms 経過（Wi-Fi 不調・ブラウザのフリーズ） |
| Jetson 指令途絶 | 自律中に Jetson の `$D` / `$S` が 300ms 途絶 |
| Jetson 停止指令 | 自律中に `$S` を受信 |
| WebSocket 切断 | 操縦者の切断を検知した時点 |
| タブ非表示 | ブラウザのタブ切替・画面オフ |
| 停止操作 | 停止ボタン / Space |
| 起動時 | PWM=0、DIR=Low で初期化（Wi-Fi より先） |

## 設定（include/config.h）

| 項目 | 既定値 | 説明 |
|---|---|---|
| `LEFT_/RIGHT_PWM_PIN` | 25 / 32 | PWM ピン |
| `LEFT_/RIGHT_DIR_PIN` | 26 / 33 | DIR ピン |
| `LEFT_/RIGHT_INVERT` | false / true | 回転方向の反転（前進で片輪が逆転する場合に切り替え） |
| `PWM_FREQ_HZ` | 20000 | PWM 周波数 [Hz] |
| `MAX_SPEED` | 1.0 | 出力上限の初期値（0〜1）。Web で変更・保存した値が優先されます |
| `MAX_ACCEL` | 2.0 | 1 秒あたりの速度変化の上限 |
| `WATCHDOG_MS` | 300 | 指令途絶で停止するまでの時間 |
| `AUTO_MAX_DUTY` | 0.5 | 自律走行の duty 上限（Web の出力上限スライダーとは別） |
| `JETSON_WATCHDOG_MS` | 300 | Jetson の指令途絶で停止するまでの時間 |
| `MANUAL_TAKEOVER_INPUT` | 0.05 | 自律中にこれを超える Web 入力で手動に戻す |
| `STATUS_PERIOD_MS` | 50 | `$T` の送信周期（20Hz） |
| `WIFI_AP_SSID / PASS` | CuGo-RC / cugo-rc-1234 | アクセスポイントの名前とパスワード |

変更したら `pio run -t upload` で書き込み直してください。

## 開発

- 操縦ロジック（加減速・ウォッチドッグ・操縦権・指令解析・動作テスト・シリアルプロトコル・モード調停）は `lib/control/` にあり、Arduino に依存しません。PC 上でテストできます:

  ```bash
  ./tests/run.sh
  ```

- Web UI は `web/` にあります。ビルド時に `scripts/embed_web.py` が gzip してファームウェアに埋め込みます。
